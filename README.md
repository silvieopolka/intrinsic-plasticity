# intrinsic-plasticity
This repository contains the final project of the blockseminar "Hackathon on Spiking Neural Networks: Model Diversity" (SS 2026) by Group 1 (Christoph Herweg, Silvie Opolka, and Joram Vornmoor).
- The Jupyter Notebook `code.ipynb` contains all functions used.
- The folder `Img` contains all individual plots generated for random_state=42, as well as the general observation plots (averaged over all three random states).
- The `SNN_data.csv` contains the metric scores of all experiment runs.
